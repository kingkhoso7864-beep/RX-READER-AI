## 📌 About the Project

Rx Reader AI is an AI-powered healthcare assistance web application designed to help users manage prescription information and medication routines in one place.

The project addresses a real-world problem: patients may struggle with handwritten prescriptions, remembering medication timings, organizing multiple medicines, and keeping track of previous prescriptions.

Rx Reader AI combines AI-powered prescription processing with medication scheduling, reminders, prescription history, safety assistance, and an AI assistant.

---

## 🎯 Problem

Managing prescriptions and medicines can be difficult because of:

- Hard-to-read handwritten prescriptions
- Forgotten medication timings
- Managing multiple medicines
- Lost or disorganized prescription records
- Difficulty understanding medication information
- Lack of an organized medication routine
